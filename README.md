# Data Warehouse and Analytics Project

A SQL Server data warehouse built on the medallion architecture (Bronze, Silver, Gold). The project covers ETL pipelines, dimensional modeling and SQL-based analytics.

## Project Requirements

### Data Engineering: Building the Data Warehouse

#### Objective
Build a SQL Server data warehouse that consolidates sales data from two source systems and supports analytical reporting and decision-making.

#### Specifications
- **Data sources:** Load data from the ERP and CRM systems, provided as CSV files.
- **Data quality:** Clean the data and resolve quality issues such as duplicates, nulls and inconsistent formats before analysis.
- **Integration:** Combine both sources into a single data model designed for analytical queries.
- **Scope:** Use the latest dataset only. Historization is not required.
- **Documentation:** Document the data model for both business stakeholders and analytics teams.

### Data Analytics: BI and Reporting

#### Objective
Develop SQL-based analytics on the Gold layer to provide insight into:
- Customer behavior
- Product performance
- Sales trends

The results give stakeholders the key business metrics needed to support decisions.
